# Custom Jacket Studio

Use my uploaded full-page product design visual as the PRIMARY design reference.

Recreate this design as closely as possible. Match its layout, proportions, spacing, typography, product viewer size, image gallery, customization panel, buttons and lower sections.

Use my separately uploaded original jacket images to preserve the actual product design.

Do not simply insert the reference screenshot as a background image. Build every section as real responsive website components.

The 3D jacket viewer must support real GLB/GLTF model loading, mouse drag rotation, zoom, front/back views, fullscreen and mobile touch controls. Until an actual model is provided, use a clearly identified image-based preview fallback.

Do not change the visual direction or invent a different layout. no exatra only single product page !
